Kimi K3

How memory changes across sequence length and model depth

A deep language model moves information in two directions: across the tokens of a conversation and through the layers that transform each token. Kimi K3 changes both routes. Kimi Delta Attention manages sequential memory, while Attention Residuals changes how later layers combine earlier representations.

Sequence length and depth are different axes

Picture a grid. Columns are successive tokens; rows are successive layers. Attention across tokens asks which earlier words matter to the current word. Mixing across layers asks which earlier representation of this same position remains useful. Both can involve weighted combinations, but they solve different problems.

The K3 model card specifies 69 Kimi Delta Attention layers and 24 gated-MLA layers within a 93-layer model. Its 2.8 trillion total parameters include sparse experts, with about 104 billion active per token. The official announcement was July 16, but the downloadable weight repository began on July 27; this folder uses the weight-release date.

[1] [2]

The model therefore preserves both a recurrent route through token history and an attention route that can retrieve prior context. The size of the total parameter set tells us little by itself about either route’s context-memory cost.

Forgetting can be selective within a memory

Kimi Delta Attention extends Gated DeltaNet with finer-grained, channel-wise gating. A channel is a coordinate of the internal representation, not a labeled human concept. The component paper also develops a chunkwise algorithm for efficient computation. Its original Kimi Linear release predates K3, so K3 should be read as a larger integration of this mechanism.

[3]

As an analogy, imagine tracking a meeting’s current speaker and the project’s deadline. At a speaker change, one part of the memory should change quickly while another should persist. A single decay knob weakens everything together. Separate gates allow different coordinates to retain information for different durations. The analogy motivates selective forgetting; it does not imply that a trained coordinate literally represents a deadline.

The toy memory curves show why recurrence is attractive. A fixed-size state does not add one new entry for every new token. However, finite state must compress information, and the remaining MLA layers still have a growing cache. The whole K3 model is not constant-memory.

Later layers can select earlier representations

A conventional residual connection adds a layer’s output to the representation already flowing through the network. Repeating this means that contributions accumulate along depth. Attention Residuals replaces fixed-weight accumulation with learned, input-dependent attention over earlier representations. The component paper also proposes block-level aggregation to reduce the memory and communication cost of keeping every intermediate output.

[4]

Use a numerical teaching example. Suppose three earlier scalar representations are 2, 5 and −1. Adding them gives 6. A normalized attention mixture with weights 0.2, 0.7 and 0.1 gives 0.2×2 + 0.7×5 − 0.1 = 3.8. The second operation can emphasize one source and diminish another; it is not the same operation as addition followed by a global scale.

This is attention along depth. It does not replace attention between tokens. A layer may need both: retrieve relevant earlier words, then choose which level of processing contains the features needed for the next transformation.

A larger model is also a systems design

K3 also uses a Stable LatentMoE framework and a low-bit training/deployment recipe. The official model card lists 16 selected routed experts from 896, two shared experts, and quantization-aware training with MXFP4 weights and MXFP8 activations. These choices address different costs and should not be collapsed into one efficiency number.

[1]

For a fair experiment, vary one mechanism while holding data, compute and evaluation fixed. A release comparison changes many ingredients at once. The component papers provide more targeted evidence than a flagship leaderboard table, while the released checkpoint demonstrates that the ingredients can be assembled into a working system.

The conceptual advance is a separation of questions: what should persist through time, what should remain retrievable, and which earlier layer representation should a later layer use? Each requires its own memory and computation accounting.

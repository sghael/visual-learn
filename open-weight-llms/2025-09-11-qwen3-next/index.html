Qwen3-Next

How a running memory and a searchable history cooperate

Reading a long conversation creates a choice: keep every detail available for retrieval, or continually fold the past into a compact state. Qwen3-Next combines both strategies. Most layers update a running memory; periodic attention layers retain access to individual earlier tokens.

Two different meanings of remembering

A notebook preserves each line so that you can look it up later. A running total preserves a conclusion while discarding the list that produced it. Both are memories, but they answer different questions. From a total of 27 you cannot recover whether the last two entries were 10 and 17 or 8 and 19.

Ordinary cached attention resembles the notebook: it stores key/value representations of previous tokens. A recurrent layer resembles the running summary: new input updates a fixed-size state. The Gated DeltaNet paper describes a matrix-valued associative memory with both forgetting and targeted updates. Its state size is set by architecture, not by the length of the conversation.

[1]

The widget compares a toy 256-scalar state with 64 cached scalars per token. At 128 tokens the latter contains 8,192 scalars; the former still contains 256. Those are deliberately small teaching dimensions. Equal scalar counts would not mean equal representational ability.

Correct an association instead of accumulating it

The delta rule changes an existing association by its prediction error. In a scalar teaching example, let the current stored value be 6 and the new target be 10. With write strength one half, the update is 6 + 0.5 × (10 − 6) = 8. Repeating the same observation gives 9, then 9.5. Blindly adding 10 every time would instead make the state grow without representing the desired value.

Gated DeltaNet adds a learned decay of the old state before this correction. For example, a retention factor of 0.5 first turns 6 into 3; the same half-strength correction toward 10 then gives 3 + 0.5 × (10 − 3) = 6.5. The decay answers how much of the current memory to retain; the delta update answers how to revise the association selected by a key. The real operation uses vectors and matrices, so different keys may overlap. Our scalar example isolates the mechanism without pretending that one human-readable fact occupies one slot.

Keep a direct-retrieval route in the stack

The released 80B-A3B model has 48 layers arranged as twelve repetitions of three Gated DeltaNet layers followed by one gated-attention layer. It also uses 512 routed experts, selecting 10 per token, plus one shared expert. These are separate savings: recurrent layers reduce attention-history work, while sparse experts reduce the feed-forward weights used by a token.

[2]

Imagine a long meeting transcript. A compact state could track the current plan and recurring participants. A full-attention layer can still consult the stored representation of an unusual identifier mentioned near the start. Access to that representation does not guarantee that the model will reproduce the identifier correctly. This example is a motivation for combining the mechanisms, not an assertion that the model assigns these human roles to particular layers.

The full-attention layers still have a growing cache. Calling the whole hybrid “constant-memory” would hide that remaining cost. Some layers use bounded recurrent state while others preserve a growing retrieval history. This also differs from sliding-window attention, which keeps an explicit recent history and discards entries outside its window.

Sparse arithmetic needs a matching implementation

Qwen3-Next also includes multi-token prediction, which can supply draft tokens for speculative decoding. Drafts must be checked by the main model. The model card warns that actual throughput depends strongly on the serving implementation and that multi-token prediction is not generally available in the basic Transformers path.

[2]

The practical experiment therefore has several axes: context length, batch size, attention implementation, expert placement and draft acceptance. A small active-parameter count does not guarantee a correspondingly small wall-clock time. The machine still stores the full experts, moves activations, reads memory and coordinates work.

Its native context is 262,144 tokens, with an extension recipe documented separately. The Instruct checkpoint covered here is a direct-answer model; the companion Thinking checkpoint is distinct. Confusing the two can change both latency and the shape of generated output.

[2]

What this tutorial leaves out

  • The state widget shows scaling behavior, not a faithful implementation or memory estimate for the released model.
  • Gated DeltaNet originated in earlier research; Qwen3-Next’s contribution is its model and systems integration.

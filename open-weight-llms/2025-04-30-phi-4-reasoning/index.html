Phi-4-reasoning · reasoning-plus

How teachable examples and verifiable rewards shape a compact reasoner

A model can have enough knowledge to approach a problem while still failing to organize a reliable solution. Phi-4-reasoning targets that gap with selected demonstrations. Its reasoning-plus variant adds a second kind of feedback: compare several attempted solutions by their outcomes.

5 sections · about 8 minutes · Reasoning

Release: 2025-04-30. Public reasoning and reasoning-plus weights launched April 30, 2025. The underlying Phi-4 was a prior release.Model: 14B dense · SFT and SFT+RL variantsWeight license: MIT

Begin with an already trained model

Microsoft released Phi-4-reasoning and reasoning-plus on April 30, 2025. These 14B models build on Phi-4; the plus variant adds reinforcement learning after supervised fine-tuning. The release also included a separate mini-reasoning model, which should not be conflated with the 14B pair studied here. [1]

The original Phi-4 report emphasizes synthetic data built from carefully selected source material, together with filtered web, code and acquired data. Its experiments also found weaknesses when removing ordinary web information entirely. A synthetic-heavy training recipe is not a claim that generated data replaces every form of external knowledge. [2]

For an invented geometry question, knowing the area formula is only a starting point. The model must identify the relevant lengths, select the formula, substitute the values and check units. A worked demonstration supplies a sequence in which these decisions are made explicit.

Choose problems near the model’s boundary

The reasoning report describes selecting prompts near Phi-4’s current capability boundary, then obtaining long demonstrations from o3-mini. Supervised fine-tuning teaches the model to generate these solution sequences. This is sequence imitation, distinct from matching a teacher’s full probability distribution at every token. [3]

Imagine three practice problems. The model always solves the first; it sometimes solves the second; it cannot make meaningful progress on the third. If time is limited, the middle problem may offer a useful combination of challenge and learnability. This is an intuition for selection, not a measured learning law.

The teacher’s explanation also needs checking. A correct final number can be reached through a mistaken step, and a fluent rationale may omit an essential assumption. Curating demonstrations means checking both what the student is asked and what behavior it is being asked to imitate.

Several attempts create a local comparison

The plus model uses group relative policy optimization, or GRPO. Sample multiple answers to the same prompt, score them, and compare each reward with the group. The actual Phi reward includes correctness, length, format and repetition considerations. Its correctness checks use extracted answers and equivalence tests, with external language-model verifiers as a fallback when answer extraction fails; this is not an entirely deterministic proof checker. The toy below isolates the group-relative signal and omits the rest. [3]

In the mixed example, rewards are 0, 0, 1 and 1. Their mean is 0.5 and population standard deviation is 0.5. Subtracting the mean and dividing by that deviation gives −1, −1, +1 and +1. These signs indicate which sampled answers did better or worse than the group average.

Now choose “all equal”. Every difference from the mean is zero, so this toy supplies no within-group ranking signal. It does not prove the answers are good. All four could be correct, all four could be wrong, or the scoring rule could have failed to distinguish them.

Reward design determines what is being practiced

Consider a verifier that checks only whether the last line contains “12”. It may reward an answer with broken reasoning that happens to end in 12. Adding format checks changes behavior, but those checks still do not establish mathematical validity. The scoring rule defines what evidence training can use.

The original Phi-4 work also explores finding pivotal points in generated answers to construct preference pairs. That is another way to focus supervision on consequential decisions rather than treating all portions of an answer as equally informative. It belongs to the base model’s post-training recipe, not a newly invented property of GRPO. [2]

Outcome feedback and demonstrations can complement one another: demonstrations show a route worth imitating; rewards discriminate among attempted routes. Neither guarantees that the visible reasoning text faithfully explains the model’s internal computation.

More generated work has a cost

The public reasoning-plus card identifies a 32K-token context and an MIT-licensed 14B dense model. Its outputs contain a reasoning portion followed by a response. That format changes how generation time is spent, even though the stored parameter count remains the same. [4]

Take an illustrative fixed generation rate of twenty tokens per second. A 200-token answer needs about ten seconds of generation; a 2,000-token answer needs about one hundred. Real systems have varying rates and prompt-processing costs, but the arithmetic explains why longer reasoning is a resource decision.

Evaluate accuracy alongside latency and generated length. A longer answer may help with a hard problem, repeat an error, or merely restate the question. Phi-4-reasoning’s contribution is a documented, data-centered path to useful reasoning behavior, not a rule that more visible thinking always produces a better answer.

What this tutorial leaves out

  • The widget is only a simplified advantage calculation, not Phi’s full training loss.
  • Sequence imitation is not the same as token-distribution distillation.
  • Longer reasoning is not guaranteed to improve an individual answer.

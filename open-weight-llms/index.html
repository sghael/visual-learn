Open-weight language models

The ideas that changed what a model can do, and what it costs to run

A language model can improve by learning from better examples, storing the past differently, activating fewer weights, or spending more computation before answering. These tutorials follow those mechanisms from a small worked example to the released model.

A small vocabulary

Token
A unit the model processes: often a word fragment, sometimes a special control symbol or an encoded piece of an image.
Parameter / weight
A learned number. Billions of these numbers implement transformations; they are not a database of separately stored facts.
Attention
A learned comparison between a query and earlier keys, used to mix the associated values into the current representation.
KV cache
The keys and values retained from preceding tokens, so generation need not recompute them. This is distinct from model-weight memory.
Expert
A feed-forward network selected by a router inside a layer. It need not correspond to a human-readable specialty such as medicine or mathematics.
Post-training
Training after the base next-token or denoising objective, to shape instruction following, preferences, reasoning, and interaction.
Distillation
Training a student using a teacher's outputs or distributions. The details differ: imitation of full solutions is not identical to matching token probabilities.
Open weights
Downloadable learned parameters under a stated license. Training data, training code, and unrestricted reuse do not automatically follow.

Coverage and evidence

This is a curated history of distinct technical contributions in public-weight language-model families, researched through October 3, 2026. It includes Llama 2 and Mistral 7B as nearby 2023 foundations for the roughly three-year window. It does not claim to list every checkpoint, fine-tune, quantization, or unpublished training trick.

One dated folder covers a named release or closely related variants that teach the same mechanism. Dates refer to public weight availability where verifiable; each tutorial explains announcement, staging, and paper-date differences. Later releases receive their own tutorial when they add a distinct, documented mechanism.

Every tutorial links to primary sources beside model-specific claims and lists the relevant paper sections. Reported results remain attributed to their authors. The figures calculate transparent teaching examples; they do not run these models, predict accuracy, or establish benchmark rankings.

License descriptions identify the published weight terms and are not a permission grant. Some families use custom licenses. The lesson distinguishes what can be downloaded from what can be independently reproduced.

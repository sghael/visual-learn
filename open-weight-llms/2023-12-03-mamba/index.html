Mamba

How a model can remember by updating a state instead of keeping every token

Reading a long story does not require keeping a literal copy of every sentence in your working memory. A model can also carry a compressed state forward. The difficulty is deciding what to retain. Mamba made that decision depend on the current input while preserving an efficient way to train the sequence model.

Two ways to carry the past

During cached generation, full causal attention keeps keys and values for earlier tokens. Each new query can compare itself with that history. A recurrent model instead transforms a fixed-size state: a collection of numbers passed from one step to the next. The state is a summary, so recovering an arbitrary past token becomes a learned compression problem.

The Mamba paper frames selection as a way to improve this compression. Input-dependent parameters determine what enters the state and how its contents evolve. This extends earlier structured state-space models; it does not invent recurrence or selective memory from nothing. [1] The tradeoff is concrete: storing more history supports direct retrieval, while keeping a fixed state makes generation memory independent of the number of earlier tokens for that recurrent layer.

A distractor should not erase a useful value

Consider a deliberately tiny memory cell. It receives the sequence 1, 0, 0, 0, 2, 0, 0, 0. Treat nonzero values as signals and zeros as distractors. The cell updates according to h_new = (1 − g) h_old + g x. This example is a scalar teaching device, not a full Mamba layer.

With a fixed gate of 0.5, the first signal becomes 0.5, then 0.25, 0.125, and 0.0625 as zeros arrive. With a selective gate, use one for signals and zero for distractors. The state holds one until the two arrives, then holds two. The difference is the input-dependent decision, not a larger memory.

Before stepping the figure, predict the state after the fourth input. Then switch to the fixed gate and compare. Real Mamba uses learned, continuous, multidimensional transformations. Its scalar special case connects to a gated recurrence, as the paper’s appendix explains. [1]

Sequential meaning need not mean sequential training

At generation time, a recurrence naturally advances one token at a time. Training has the full sequence available. A sequence of affine updates can be composed associatively: applying one update and then another can be represented as a single combined update. This opens the door to parallel prefix computations.

Mamba combines input-dependent selection with a hardware-aware scan implementation. Its code exposes a selective state-space module and language-model checkpoints, so the algorithm is not only a mathematical proposal. [2] Parallelism changes how the known sequence is evaluated; it does not allow a future generated token to be known before it has been produced.

For a concrete analogy, multiplying many small matrices can be grouped into pairs, then pairs of pairs, instead of carrying out the entire chain on a single thread. Associativity preserves the result in exact arithmetic, although finite-precision kernels can differ numerically. GPU efficiency also depends on memory movement, not just the number of operations.

Compression has a price

A fixed state cannot preserve an unlimited collection of unrelated facts at arbitrary precision. Suppose a prompt contains thousands of random key-value pairs. Attention can retain an addressable representation of each pair; a recurrent state must encode them into a bounded object. That is a reason to test retrieval and copying, not assume that good average language-model loss settles every task.

The official releases include models trained on the Pile and a separate SlimPajama checkpoint. Those are pretrained language models, not automatically instruction-following assistants. [2] The model repository records the first 130M weight release on December 3, 2023. [3] Later Mamba generations and hybrid models change the state update or reintroduce attention. Their successes do not retroactively describe the original release.

What this tutorial leaves out

  • The recurrence is a hand-designed teaching example and omits learned projections, multidimensional state, discretization, convolution, and gating in the actual block.
  • Constant recurrent state does not mean constant total training memory or unlimited reliable context.
  • No benchmark speedup is inferred from the storage chart.

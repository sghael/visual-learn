Qwen3.5

How visual tokens join a hybrid language model

A chart is not merely a paragraph waiting to be transcribed. Its axes, geometry, labels and marks jointly carry meaning. Qwen3.5 trains a visual-language model around a hybrid sequence processor, combining richer input with an architecture designed for long contexts.

The interface between pixels and language

A language model operates on vectors. An image encoder turns visual input into vectors too, and a connecting projection makes those representations usable by the language backbone. Early fusion means visual and textual training signals participate together during the foundation training process, rather than only attaching a visual adapter after a text model is finished.

Qwen3.5’s first open flagship, 397B-A17B, is explicitly described as a causal language model with a vision encoder. Its release emphasizes early multimodal fusion and a mixture-of-experts backbone. The name describes roughly 397 billion total parameters and 17 billion active per token; it is not the size of an ordinary dense network.

[1]

Consider a scatterplot with one outlier. Optical character recognition could recover the title and axis labels but miss the point’s location. A visual representation must carry spatial evidence alongside text. Conversely, a perfectly preserved picture still requires reasoning to decide whether that outlier invalidates the conclusion.

Three recurrent layers, then a retrieval layer

The flagship retains the architectural pattern introduced in Qwen3-Next: three Gated DeltaNet layers followed by one gated-attention layer. Qwen3.5 scales that pattern to 60 layers. Its expert layers contain 512 routed experts, activate 10, and include one shared expert. These are inherited mechanisms developed further in a multimodal setting, rather than techniques first invented by this release.

[1]

Why does the combination matter for images? A document containing many pages can create a long stream of visual and textual representations. A recurrent summary can update without adding another full history entry to that layer. The remaining attention layers retain a route to specific earlier representations. A visual model must decide what to preserve before later questions reveal which details matter.

A useful training example joins perception and consequence

Suppose a training problem shows a line chart and asks which month has the largest increase. A good target must depend on the chart: read adjacent values, compute their differences, then compare. If the answer can be guessed from the title alone, the training example rewards a shortcut.

This gives an experimental test for multimodal learning. Replace the picture while keeping the question unchanged. A model using the visual evidence should change its answer when the relevant marks change. Remove the axis scale and the correct response may become uncertainty rather than a numerical claim. These are proposed diagnostic experiments, not reported Qwen benchmark results.

The model card describes asynchronous reinforcement-learning infrastructure for agent environments. Generation and learning can proceed on different schedules, allowing the system to collect and score many interactions. More environments do not make every reward reliable: a visual answer can look plausible while misreading a small label, and a successful tool action can still be unrelated to the requested goal.

[1]

A downloadable checkpoint and a hosted product differ

The model card separates the open checkpoint from the corresponding hosted Qwen3.5-Plus product. It lists a native 262,144-token context for the checkpoint and describes an extension recipe; hosted tools and default context settings are additional product features. Downloading weights does not automatically reproduce those services.

[1]

For a reproducible test, record image preprocessing, resolution, prompt, thinking settings, context length and the serving engine. A smaller image may save tokens while erasing the very legend the question requires. A larger image may preserve details while increasing time and memory. Neither choice can be judged by parameter count alone.

The central innovation is the joint design problem: train the model to use visual evidence, keep enough context for that evidence to remain useful, and make the resulting computation affordable. The page’s figures isolate those mechanisms so that a reader can distinguish them from vendor benchmark rankings.

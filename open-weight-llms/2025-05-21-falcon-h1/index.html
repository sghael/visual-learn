Falcon-H1 · 0.5B to 34B

How attention and a recurrent state can work beside each other

An attention cache keeps individually addressable representations of past tokens. A recurrent state repeatedly compresses what it has seen. Falcon-H1 combines these mechanisms in parallel inside a block, allowing the same current input to use both kinds of information before their outputs are mixed.

A hybrid family, rather than one fixed size

TII announced Falcon-H1 on May 21, 2025. Its technical release presents base and instruction-tuned variants spanning 0.5B, 1.5B, 1.5B-Deep, 3B, 7B and 34B. The later technical paper supplies the detailed architecture and training study; its July publication date is not the model-family launch date. [1] [2]

Here, hybrid means combining transformer attention with a state-space sequence mechanism based on Mamba-2. It does not mean switching between two complete assistants. Both branches are learned components of the same language model.

Imagine reading a meeting transcript. Tracking the current topic can benefit from a compact evolving representation. Recovering a particular earlier date may benefit from attending to its stored token representation. This is an intuition for complementary operations, not a promise that one branch always handles topics and the other always handles dates.

Both branches receive the same input

Falcon-H1’s report specifies a parallel arrangement. Attention and SSM branches process the same block input; their outputs are concatenated before a learned output projection. This differs structurally from alternating attention and recurrent layers, where one layer’s result becomes the next layer’s input. Parallel hybridization itself has prior work; Falcon-H1 adopts and studies it. [3]

A compact equation is mix(x) = W · [attention(x); SSM(x)]. The semicolon means concatenate: place the two vectors end to end. W is a learned matrix that mixes those channels. The equation omits normalization, residual connections and other block components.

For invented outputs [2, 1] and [5, −1], concatenation gives [2, 1, 5, −1]. An example projection row [1, 0, 0.5, 0] produces 4.5. The projection can combine evidence from both branches without demanding that their intermediate coordinates have the same meaning.

The hybrid retains two different memory terms

The recurrent branch updates a fixed-size state. The attention branch keeps a cache that grows with sequence length. Combining them therefore does not make the entire model constant-memory. It introduces an architectural budget: how much work and representation width to allocate to each branch.

In the illustrative chart, the recurrent component stores 256 scalars while the attention component adds 64 scalars per token. At 128 tokens their sum would be 8,448 scalars; at 256 tokens it would be 16,640. The widget displays the components separately. Its invented dimensions are not Falcon-H1 configuration values.

The report treats attention and SSM widths as adjustable design choices. Reducing attention’s share can reduce its cost while keeping a direct route to previous token representations. The right mixture must be evaluated; the diagram cannot predict whether a smaller branch retains sufficient capability. [3]

Equal parameter counts can hide different paths

The team’s technical post discusses the tradeoff behind the 1.5B-Deep variant: more depth can improve their measured quality while imposing an efficiency cost. It also describes tuning the balance of attention and SSM heads and their training scales. The result is a family of configurations rather than a single universally optimal ratio. [2]

Imagine distributing a fixed amount of computation across a few wide steps or many narrower steps. The latter creates more successive transformations; the former exposes more parallel work within a step. The same parameter total does not determine dependency depth, memory traffic or latency.

“Parallel” in an architectural diagram also does not guarantee that a runtime executes both branches simultaneously on separate hardware. Actual scheduling, tensor shapes and kernels determine the overlap. The topology creates an opportunity that an implementation must realize.

Check the checkpoint and workload you actually need

The official 7B base card identifies a causal decoder hybrid and the custom Falcon-LLM license. A base checkpoint learns continuation; instruction tuning changes its response behavior. Choose the intended variant before attributing an assistant’s qualities to the architecture alone. [4]

For a useful comparison, measure short-question latency, long-prompt processing, long generation and retrieval accuracy separately. A model can improve one workload without improving all of them. Keep context length and batch size visible beside any memory or throughput result.

Falcon-H1’s central idea is the location of the combination: attention and recurrence meet inside a shared block. That creates a continuous design space over their widths and capacities, while preserving the need to measure the resulting system as a whole.

What this tutorial leaves out

  • Hybrid memory includes both fixed-state and growing attention-cache components.
  • The block diagram is architectural; it does not promise simultaneous kernel execution.
  • The state widget uses invented scalar counts and does not predict real memory or quality.
  • Model-family size labels are rounded names, not exact parameter inventories.
